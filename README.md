# BrightFix - Photo Editor

BrightFix is a web-based digital image processing and photo editing application built using Python and Streamlit. It provides a wide range of interactive tools to enhance, transform, and apply creative effects to your images easily.

## Features

- **Basic Adjustments:** Modify Brightness, Contrast, Saturation, and Sharpness.
- **Interactive Crop & Resize:** Crop images using an interactive box tool and resize with aspect ratio control.
- **Rotate & Flip:** Rotate at 90°, 180°, 270° and flip horizontally or vertically.
- **Image Effects:** Grayscale, Sepia, Negative, Thresholding, Edge Detection, Blur, and Sharpen.
- **Extra Enhancements:** Auto Enhance, Pixelate, Posterize, Vignette, Pencil Sketch, and Cartoon effect.
- **AI Background Blur:** Blur the background of an image using advanced AI masking (`rembg`).
- **Watermark:** Add custom text watermarks to your edited photos.
- **Histogram Analysis:** View real-time RGB pixel intensity distribution histograms.
- **Flexible Export:** Download your edited images in PNG or JPEG formats with custom file naming.

## Tech Stack

- **Python**
- **Streamlit** (Web Framework)
- **Pillow (PIL)** (Image Processing)
- **NumPy & Matplotlib** (Array Operations & Histograms)
- **Rembg** (AI Background Removal)
- **Streamlit-Cropper** (Interactive Cropping)
